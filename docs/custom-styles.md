# Кастомные стили (темы)

Микро-справочник по тому, как устроена кастомизация внешнего вида OutClash:
какие есть слои, какие поля доступны, как их менять и как сгенерировать тему промптом.

---

## TL;DR

- Внешний вид настраивается через **CSS-переменные** (дизайн-токены) в формате `oklch`.
- Кастомная тема — это обычный `.css` файл, который кладётся в
  `<userData>/themes/` и инъектится в окна поверх базовых стилей.
- Сменить тему можно в **Настройки → Внешний вид → Тема** (раздел скрытый, см. ниже).
- Подписка может прислать свою тему через HTTP-заголовок `custom-css`.

---

## Три слоя кастомизации

| Слой | Поле конфига | Что это | Где меняется |
|------|--------------|---------|--------------|
| Режим темы | `appTheme` | `'system' \| 'light' \| 'dark'` — светлый/тёмный/системный | Настройки → Внешний вид → «Цвет фона» (Авто / Тёмная / Светлая) |
| Кастомная тема | `customTheme` | имя `.css` файла, по умолчанию `default.css` | Настройки → Внешний вид → «Тема» (скрытый раздел) |
| Тема профиля | `customCss` (в `ProfileItem`) | имя `.css` файла, прилетевшего из подписки | Автоматически при переключении профиля |

### 1. Режим темы (`appTheme`)

Переключает светлую/тёмную палитру. Технически добавляет/снимает класс `.dark`
на корне документа (через `next-themes`), что подменяет набор CSS-переменных.
Значение `system` следует за темой ОС.

### 2. Кастомная тема (`customTheme`)

Файл `.css` из папки тем. При выборе темы её содержимое **инъектится** в главное
и плавающее окна (`webContents.insertCSS`) и переинъектится при каждой смене.
Базовые стили приложения при этом остаются — тема накладывается сверху.

- Файлы лежат в `<userData>/themes/` (`%APPDATA%/outclash/themes/` на Windows,
  `~/Library/Application Support/outclash/themes/` на macOS,
  `~/.config/outclash/themes/` на Linux).
- Имя темы в списке = первая строка-комментарий `/* Название */`, иначе имя файла.
- `default.css` всегда первый в списке (если файла нет — это «пустая» тема без оверрайдов).

### 3. Тема профиля (`customCss`)

В подписке можно отдать заголовок `custom-css: https://.../theme.css`
(совпадение по суффиксу имени заголовка, регистр не важен). При обновлении профиля
файл скачивается в папку тем как `custom-<hex>.css` и поле `customCss` профиля
указывает на него. При переключении на этот профиль приложение само ставит
`customTheme = customCss`, то есть подписка приносит свой брендинг.

> ⚠️ Поэтому при смене профиля выбранная вручную тема может замениться на тему профиля.

## Доступные поля (CSS-переменные)

Все токены определены в `src/renderer/src/assets/main.css`: в `:root` — светлая
палитра, в `.dark` — тёмная. Цвета — в формате `oklch(L C H [/ alpha])`.
Переопределяй именно переменную — её читают все компоненты сразу.

### Базовые поверхности и текст
| Переменная | Назначение |
|------------|------------|
| `--background` / `--foreground` | фон приложения / основной текст |
| `--card` / `--card-foreground` | карточки / текст на карточках |
| `--popover` / `--popover-foreground` | поповеры, выпадашки |
| `--muted` / `--muted-foreground` | приглушённый фон / вторичный текст |

### Акценты и состояния
| Переменная | Назначение |
|------------|------------|
| `--primary` / `--primary-foreground` | основной акцент (кнопки, активное) |
| `--secondary` / `--secondary-foreground` | вторичный акцент |
| `--accent` / `--accent-foreground` | подсветка hover/выделения |
| `--destructive` / `--destructive-foreground` | опасные действия, ошибки |
| `--success` / `--success-foreground` | успех |
| `--warning` / `--warning-foreground` | предупреждения |

### Главный тумблер вкл/выкл (большая кнопка питания)
| Переменная | Назначение |
|------------|------------|
| `--stroke-power-off` | обводка в выключенном состоянии |
| `--gradient-start-power-off` / `--gradient-end-power-off` | градиент «выкл» |
| `--stroke-power-on` | обводка во включённом состоянии |
| `--gradient-start-power-on` / `--gradient-end-power-on` | градиент «вкл» |

### Карточки профилей
| Переменная | Назначение |
|------------|------------|
| `--profile-active` / `--stroke-profile-active` | фон/обводка активного профиля |
| `--profile-inactive` / `--stroke-profile-inactive` | фон/обводка неактивного |

### Границы, поля ввода, фокус
| Переменная | Назначение |
|------------|------------|
| `--border` | границы по умолчанию |
| `--input` | границы полей ввода |
| `--ring` | кольцо фокуса |
| `--stroke` | общая тонкая обводка |

### Сайдбар
`--sidebar`, `--sidebar-foreground`, `--sidebar-primary`,
`--sidebar-primary-foreground`, `--sidebar-accent`, `--sidebar-accent-foreground`,
`--sidebar-border`, `--sidebar-ring`.

### Графики
`--chart-1` … `--chart-5` — цвета серий на графиках трафика.

### Геометрия
`--radius` — базовый радиус скругления (от него считаются `--radius-sm/md/lg/xl`).

### Полезные классы (не переменные)
- `.app-drag` / `.app-nodrag` — зоны перетаскивания окна.
- `.wc-mac` / `.wc-win` + `.wc-close/.wc-minimize/.wc-maximize` — кнопки управления окном.
- `*::-webkit-scrollbar` — скроллбары.
- `.driver-popover*` — окна онбординг-тура.

## Как менять

### Через UI (рекомендуется)
1. Открой раздел тем: **Настройки → Внешний вид**. Блок «Тема» скрыт —
   разблокируется тапом по номеру версии **7 раз** (Настройки → низ страницы).
2. После разблокировки рядом с селектом «Тема» появятся три кнопки:
   - **Загрузить тему** (облако) — тянет готовые темы из theme-hub.
   - **Импортировать тему** — добавляет твои `.css` файлы в папку тем.
   - **Редактировать тему** — открывает CSS-редактор (Monaco) для текущей темы;
     по «Подтвердить» файл сохраняется и тема сразу применяется.
3. Выбери тему в селекте — она применится мгновенно.

> Редактирование при выбранном `default.css` создаст реальный файл `default.css`
> в папке тем (по умолчанию его там нет).

### Вручную
1. Положи `my-theme.css` в папку тем (см. пути выше).
2. Первой строкой задай имя: `/* Моя тема */`.
3. Перезайди в селект тем (или нажми «Импортировать») и выбери её.

### Минимальный пример темы

```css
/* Ocean */
:root {
  --primary: oklch(0.62 0.19 240);          /* синий акцент */
  --primary-foreground: oklch(0.98 0 0);
  --radius: 1rem;                            /* более круглые углы */
}

.dark {
  --background: oklch(0.18 0.03 250);        /* фон тёмной темы */
  --card: oklch(0.24 0.04 250);
  --primary: oklch(0.72 0.17 235);
}

/* Точечные доводки можно делать обычным CSS.
   Тема инъектится поверх — для перебивки tailwind-утилит используй !important. */
```

> Совет: меняй **переменные**, а не конкретные селекторы — так перекрасится весь UI
> консистентно. Прямые селекторы оставляй для точечных доводок.

## Промпты для генерации темы

Скопируй шаблон ниже в любую LLM — он содержит список токенов и правила формата,
на выходе получишь валидный `.css` для папки тем.

### Базовый промпт

```
Сгенерируй CSS-тему для Electron-приложения (UI на Tailwind v4 + shadcn).
Тема накладывается через insertCSS поверх базовых стилей.

Требования:
- Цвета только в формате oklch(L C H) или oklch(L C H / alpha).
- Переопредели CSS-переменные в :root (светлая) и .dark (тёмная).
- Первой строкой добавь комментарий с названием темы: /* Название */.
- Не используй внешние шрифты и @import.
- Контраст текста к фону — не ниже WCAG AA.

Палитра/настроение: <ОПИШИ: например «тёплый закат, оранжево-фиолетовый, мягкие тени»>.

Переопредели как минимум:
--background, --foreground, --card, --card-foreground,
--primary, --primary-foreground, --secondary, --accent,
--muted, --muted-foreground, --border, --input, --ring,
--success, --warning, --destructive, --radius,
--stroke-power-on, --gradient-start-power-on, --gradient-end-power-on,
--profile-active, --sidebar, --sidebar-primary.

Выдай только содержимое .css файла, без пояснений.
```

### Уточняющие добавки
- «Сделай только тёмную тему, светлую не трогай» → убрать блок `:root`, оставить `.dark`.
- «Подбери акцент под бренд #1E90FF» → добавить hex и попросить сконвертировать в oklch.
- «Высокий контраст / для слабовидящих» → добавить требование контраста AAA и толще `--border`.

## Где в коде (для мейнтейнеров)

| Что | Файл |
|-----|------|
| Токены/переменные тем | `src/renderer/src/assets/main.css` |
| Тип `AppTheme` | `src/shared/types/types.d.ts` |
| Поля `appTheme` / `customTheme` / `customCss` | `src/shared/types/app.d.ts` |
| Применение темы (insertCSS), скачивание, импорт | `src/main/resolve/theme.ts` |
| Триггеры применения при старте/смене | `src/renderer/src/App.tsx` |
| UI настроек темы | `src/renderer/src/components/settings/appearance-confis.tsx` |
| CSS-редактор | `src/renderer/src/components/settings/css-editor-modal.tsx` |
| Заголовок `custom-css` из подписки, тема профиля | `src/main/config/profile.ts` |
| Папка тем | `themesDir()` в `src/main/utils/dirs.ts` → `<userData>/themes/` |
| IPC темы | `resolveThemes/applyTheme/readTheme/writeTheme/importThemes/fetchThemes` |
