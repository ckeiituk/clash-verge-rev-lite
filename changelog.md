## v1.3.2

### Исправления
- Восстановлено переключение системного прокси: обновлён фоновый сервис. В 1.3.1 при включении или отключении прокси могла возникать ошибка «unknown command "sysproxy"».
- Системный прокси теперь гарантированно отключается при закрытии приложения — раньше изредка можно было остаться без интернета после выхода.
- При миграции со старой версии активный профиль теперь выбирается автоматически — раньше после переноса ядро могло стартовать без выбранного профиля.
- Установщик Windows больше не повреждает свежую установку при обновлении со старой (Tauri) версии — удаление старой версии теперь выполняется до распаковки новых файлов.
- Установщик Windows теперь убирает службу, автозапуск и зависшие процессы старой (Tauri) версии — раньше после миграции на входе в систему могли запускаться сразу два клиента и конфликтовать за системный прокси.
- На macOS/Linux при миграции теперь корректно завершаются старое приложение, его служба и зависшие процессы ядра предыдущей (Tauri) версии.
- Linux: исправлен запуск из терминала и по PATH (раньше симлинк `/usr/bin/OutClash` мог указывать в никуда).
- Миграция больше не теряет подписки при отсутствии сети на первом запуске — импорт повторяется на следующих запусках.

## v1.3.1

### Что нового
- Добавлен режим редактирования правил профиля как YAML-текста — удобнее править большие списки и порядок без визуального конструктора.
- Поддержка кастомного CSS из подписки: профиль может поставлять собственную тему, которая применяется к интерфейсу приложения.
- Header `global-mode` в подписке: автор подписки может закрепить режим маршрутизации, чтобы он не сбивался при ручных переключениях.
- Добавлены значения по умолчанию для `route-exclude-address` — частые локальные сети исключаются из туннеля сразу после установки.
- Переводы редактора Monaco для китайского, английского и русского — описания правил mihomo теперь подсказываются на языке интерфейса.

### Улучшения
- Заметно ускорена страница «Прокси»: новый рендер групп, плавная анимация открытия и более отзывчивая работа при большом числе нод.
- Ускорена страница «Подключения»: меньше перерисовок, оптимизированы запросы иконок процессов и имён приложений.
- HWID-проверка приведена к требованиям Remnawave v2.8 — пользователи с актуальной панелью авторизуются стабильнее.

### Исправления
- Восстановлено корректное поведение системного прокси после возврата приложения из офлайна.
- Починена настройка публичного DNS на macOS — изменения снова применяются ко всем активным сетевым службам.
- Исправлено отображение группы `GLOBAL`, если она переопределена в конфигурации профиля.
- Поправлен порядок правил при добавлении новых записей через визуальный редактор.
- Исправлен баг с загрузкой geo-данных (issue #89 апстрима).
